# ▶️ Running the Assessments

## Requirements

Make sure you have:

- Java JDK
- Eclipse or another Java IDE
- Google Chrome
- Selenium Java dependencies
- Internet connection

## Clone

```bash
git clone https://github.com/S-Rahul-Naik/Selenium-Assessment.git
```

## Execute

```text
1. Open the project in Eclipse.
2. Configure the Selenium Java dependencies.
3. Navigate to the required assessment.
4. Open the Java class.
5. Run it as a Java Application.
6. Observe the browser interaction.
7. Verify the expected behavior.
```
