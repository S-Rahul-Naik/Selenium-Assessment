## Project Setup

### Prerequisites

- Java JDK
- Eclipse or another Java IDE
- Google Chrome
- Selenium Java libraries
- Internet connection

### Run the Assignments

1. Open the project in Eclipse.
2. Confirm that the Selenium dependencies are configured.
3. Open an assignment class from the project.
4. Run the class as a Java application.
